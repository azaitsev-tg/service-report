Мобильное веб-приложение (Progressive Web App) корпоративного уровня для инженеров сервисного отдела. Предназначено для автоматизации сбора, форматирования и отправки технической отчетности с объектов (ремонт, диагностика, регламентное ТО) напрямую в офис.

## 🎯 Основная проблематика и решение

Работа на объектах часто сопряжена с отсутствием интернета (подвалы) и необходимостью фиксировать десятки фотографий. Данное приложение переносит всю сложную логику на сторону телефона: оно локально сжимает фото, склеивает PDF и работает **полностью в офлайне**. Версия 2.1.0 оптимизирует этот процесс за счет умного управления памятью и интуитивного UI.

## 🚀 Возможности приложения (версия 2.1.0)

* **True Offline и Автообновления:** Благодаря Service Worker приложение работает без интернета. Внедрена система «Zero-Stale»: при выходе новой версии телефон скачивает её в фоне и автоматически перезагружает страницу для применения исправлений.
* **Умное управление состоянием (Dirty State):** Интерфейс реагирует на действия пользователя. Глобальная кнопка сброса `[🗑️]` и локальные кнопки очистки разделов `[✕]` появляются только тогда, когда в полях или блоках загрузки появляются данные.
* **Защита памяти (OOM Protection):** Фотографии сжимаются «на лету» через Canvas API. После завершения работы или сброса формы приложение принудительно очищает оперативную память (`URL.revokeObjectURL`), что исключает вылеты браузера даже на старых устройствах при 50+ фото.
* **Интеллектуальные маски ввода:** Защита от опечаток в номерах заявок. Автоматическая подстановка префиксов и поддержка трех форматов: `P.XX-0000XXXX`, `ПРОЗ-XX-00XXX` и `ITSM XXXXXX` (с автокоррекцией раскладки).
* **Оптимизация под iOS Safari:** Реализован автоматический захват темы письма в буфер обмена при нажатии кнопки «Отправить», что обходит ограничения системы Apple по передаче текста вместе с файлами.
* **Premium UI & Dark Mode:** Интерфейс на базе Accordion UI экономит место на экране. Глубокая темная тема бережет заряд OLED-дисплеев в условиях длительных выездов.
* **Центр онбординга:** Боковое меню (Side Drawer) с инструкциями, базой знаний и системой мгновенной отправки баг-репортов с техническими данными устройства.

## 🛠 Технический стек

* **Vanilla JavaScript (ES6+)** — логика интерфейса, асинхронная сборка PDF.
* **pdf-lib** — клиентская генерация и мерж многостраничных документов.
* **Service Worker & Web Share API** — нативная работа с ОС и офлайн-доступ.
* **HTML5 / CSS3** — полностью автономная верстка без внешних зависимостей.

## 📱 Установка на устройство

1.  Откройте приложение в **Safari** (iOS) или **Chrome** (Android).
2.  Нажмите «Поделиться» или «Меню» (три точки).
3.  Выберите **«На экран домой»**.
4.  Иконка появится на рабочем столе. Приложение готово к работе в любых условиях.
